# Arquitectura de RobusTal

## 1. Objetivo del motor.

Este motor es un proyecto didáctico con el que me he propuesto lo siguiente:

- Soluciones elegantes y flexibles de los subproblemas.
- Diseñar para el futuro desde la primera linea.
- Optimización progresiva sobre una base que me permita implementar sin deshacer más de lo necesario.

## 2. Principios del proyecto.

- Código explícito con estilo consistente.
- Modularidad y componentes separados por responsabilidad.
- De versión simple pero completa a version optimizada.
- Dependencias justas y necesarias.
- Tests de reglas criticas.
